### **Resumen del Software: "Qualitative AI Analyzer"**

El software **"Qualitative AI Analyzer"** es una herramienta diseñada para optimizar el análisis e interpretación de datos cualitativos mediante inteligencia artificial (IA). Su arquitectura modular y escalable permite procesar documentos, realizar análisis avanzados y generar visualizaciones interactivas. A continuación, se detalla su diseño, funcionalidades y características principales, incluyendo la integración del **API Key** proporcionado.

### **1. Funcionalidades Principales**
El software está diseñado para cumplir con las siguientes funcionalidades clave:

#### **a. Procesamiento de Documentos**
- **Formatos soportados**: PDF, Word, Excel y otros formatos comunes.
- **Extracción de texto**: Procesamiento automatizado para extraer contenido textual de los documentos cargados.
- **Preprocesamiento**: Limpieza y normalización del texto para su análisis posterior.

#### **b. Análisis de Datos Cualitativos**
- **Integración con DeepSeek**: Utiliza la API de DeepSeek para realizar análisis avanzados de texto, como categorización, codificación y síntesis de datos.
- **Identificación de patrones**: Reconocimiento de temas, relaciones y patrones en los datos cualitativos.
- **Triangulación de datos**: Comparación de múltiples fuentes para aumentar la validez y confiabilidad de los resultados.

#### **c. Generación de Visualizaciones**
- **Gráficos**: Barras, líneas, diagramas de dispersión, entre otros.
- **Mapas mentales**: Representación visual de conceptos y relaciones.
- **Resumen visual**: Tablas y diagramas interactivos para facilitar la interpretación de los resultados.

#### **d. Interacción Dinámica**
- **Chatbot**: Permite a los usuarios interactuar con el sistema mediante preguntas basadas en los documentos cargados.
- **Respuestas personalizadas**: Generación de respuestas basadas en el contenido analizado.

#### **e. Gestión de Usuarios y Seguridad**
- **Autenticación**: Uso de API keys para garantizar la seguridad en el acceso.
- **Control de acceso**: Gestión de permisos para diferentes tipos de usuarios.

#### **f. Escalabilidad y Portabilidad**
- **Docker**: Uso de contenedores para garantizar la portabilidad y facilidad de despliegue.
- **Orquestación**: Configuración mediante `docker-compose` para gestionar los servicios del backend y frontend.

### **2. Diseño del Software**
El software está dividido en dos componentes principales: **backend** y **frontend**, con una estructura clara y modular.

#### **a. Backend**
El backend está desarrollado en **Python** utilizando **FastAPI** como framework principal. Sus responsabilidades incluyen:
- **Procesamiento de documentos**: Extracción y preprocesamiento de texto.
- **Integración con DeepSeek**: Comunicación con la API para realizar análisis avanzados.
- **Generación de visualizaciones**: Creación de gráficos y mapas mentales.
- **Gestión de seguridad**: Autenticación mediante API keys.

**Estructura del Backend**:
- **`app/`**: Contiene la lógica principal del backend.
  - **`api/routes.py`**: Define los endpoints para interactuar con el sistema.
  - **`services/`**: Implementa la lógica de negocio, como el procesamiento de documentos y la integración con DeepSeek.
  - **`models/`**: Define los modelos de datos utilizados en el sistema.
  - **`core/`**: Configuración central, incluyendo variables de entorno y seguridad.
- **`tests/`**: Incluye pruebas unitarias y de integración para garantizar la calidad del software.
- **`Dockerfile`**: Permite la containerización del backend.

#### **b. Frontend**
El frontend está desarrollado en **React.js**, proporcionando una interfaz de usuario (UI) moderna, dinámica y fácil de usar. Sus responsabilidades incluyen:
- **Carga de documentos**: Permitir a los usuarios subir archivos para su análisis.
- **Visualización de resultados**: Mostrar gráficos, mapas mentales y resúmenes interactivos.
- **Interacción con el chatbot**: Facilitar la comunicación entre el usuario y el sistema.

**Estructura del Frontend**:
- **`components/`**: Contiene los componentes reutilizables de la UI.
- **`services/`**: Maneja la comunicación con el backend.
- **`styles/`**: Archivos CSS/SCSS para el diseño visual.
- **`App.js`**: Componente principal que organiza la estructura de la aplicación.
- **`Dockerfile`**: Permite la containerización del frontend.
